This is a single-index specialist model — the ARDL fit, feature cache, and hybrid model weights were all trained and walk-forward-evaluated on the S&P 500 only. It intentionally doesn't offer other tickers rather than silently serving an unvalidated forecast for them.

The first forecast after a new market close can take 1–2 minutes: the service refits the ARIMA order search (15 models) on the full return history, exactly as in the evaluation. Later requests are served from cache. Each forecast uses the latest completed S&P 500 session, fetched live.

Walk-forward folds (retrained per fold)

A genuine rolling walk-forward evaluation (never a random or k-fold split) found the complex hybrid model's directional accuracy is statistically indistinguishable from a coin flip, and a Diebold-Mariano significance test shows it is measurably worse than a simple econometric ARIMA baseline (p < 0.001). This is consistent with market micro-efficiency at the one-day horizon for a heavily-traded index — not a bug to be "fixed" by tuning harder. Re-validated on 19 months of additional real data extending the evaluation window forward — the finding held, the significance sharpened.
